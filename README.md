# 🧮 Calculator Project

### 🚀 Simple, Responsive & Interactive Web Calculator

**Description:** A basic yet functional calculator built using HTML, CSS, and JavaScript, allowing users to perform standard arithmetic operations with a clean and user-friendly interface.

---

## 📌 Project Overview

This project is a **web-based calculator** that performs basic mathematical operations such as addition, subtraction, multiplication, and division.

It is designed to demonstrate core front-end development skills including DOM manipulation and event handling using JavaScript.

---

## 🚀 Features

* ➕ Basic arithmetic operations (+, −, ×, ÷)
* 🧠 Real-time input handling
* 🎨 Clean and responsive UI
* ⌫ Delete and clear functions
* ⚡ Instant calculation result
* 📱 Works on all screen sizes

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

## 📂 Project Structure

```
calculator/
│── index.html     # Calculator layout
│── style.css      # Styling and design
│── script.js      # Calculator logic
```

---

## 🧩 How It Works

1. User clicks numeric and operator buttons.
2. Input is displayed on the screen in real time.
3. JavaScript stores and processes the expression.
4. When "=" is pressed, the result is calculated and displayed.
5. Clear button resets the calculator.

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Tamer7459/calculator.git
```

2. Open the project folder.

3. Run the calculator by opening:

```
index.html
```

in your browser.
